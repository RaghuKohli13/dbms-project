Student Mental Health & Counselling Support System

This project is a Database Management System (DBMS) designed to help manage student mental health and counselling services in a structured and efficient way. The aim is to replace scattered records and manual processes with a centralized database that ensures better organization, accuracy, and accessibility of information.

The system focuses on handling student details, counsellor information, appointment scheduling, therapy sessions, and mental health assessments. It also includes logic to prevent scheduling conflicts and to identify high-risk cases through automated alerts.

Features:

* Centralized storage of student and counsellor data
* Appointment scheduling with conflict prevention
* Mental health assessment tracking (such as PHQ-9, GAD-7)
* Automated triggers for critical situations
* Structured relational database with proper normalization

Technologies Used:

* SQL
* PL/SQL
* MySQL / PostgreSQL

Project Files:

* dbms_final_project.sql → Contains database schema, tables, and queries
* report.pdf → Complete project report and documentation
